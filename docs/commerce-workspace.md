## ZayOS Commerce Workspace

Commerce Workspace is the daily operating surface for turning customer conversations into commerce work. It should not feel like only a messaging app. It should show the operating flow:

```text
Chat Message -> Customer Memory -> Product Match -> Order Draft -> COD / Delivery -> Follow-up
```

### 1. Login & Authentication

- Login form: Email/username & password
- Two-factor authentication (optional)
- SSO: Google, Microsoft
- Forgot/reset password
- Branding: ZayOS and tenant logo
- Announcements panel

---

### 2. Dashboard Overview

- Today Overview: assigned work, waiting replies, draft orders, COD today
- Needs Attention: conversations waiting, order/payment blockers, delayed rider, COD exception
- Commerce Health: inbox, orders, delivery, follow-up
- Recent Activity: latest events across conversations, orders, payments, delivery
- Quick links: Inbox, New Order, Orders, Delivery, Reports

---

### 3. Unified Inbox

- **Conversation List (Left):**
    - Filters: All, Unread, My, Team
    - Sort: Latest, priority, channel
    - Channel icons
    - Planned productivity queues: Unread, Hot Leads, VIP, Needs Attention
    - Planned assignment rules: round robin, least busy, manual, priority/VIP routing
- **Active Chat (Center):**
    - Customer summary and current commerce stage
    - Chat thread
    - Message status indicators
    - Rich content: images, videos, voice notes, files
    - Planned response timing: first response due, next response due, overdue state
- **Reply Tools (Bottom):**
    - Text composer, emoji picker
    - Canned responses
    - Attachments
    - Create order/invoice
    - Tag conversation
- **Commerce Timeline Panel (Right):**
    - Customer memory and history
    - Product intent and matched items
    - Linked orders/invoices
    - COD/payment state
    - Delivery/rider state
    - Notes and follow-up
    - Planned Commerce Timeline events: chats, orders, calls, notes, payments, complaints, delivery, COD collection, follow-up

---
